# Apartments demo

A one-page systems portfolio by Ifrah Awaale, covering the two systems that run Orfane Tower:

- **Orfane Finance Platform**: bookings, leases, meter readings, billing, bank reconciliation and reporting on a double-entry ledger, where the bank statement is the only way a bill gets paid.
- **Cleaning Operations App**: daily round scheduling, attendance from the door system, and a live board on the staff-room TVs.
- **Exception Reporting**: tenancy-vs-invoice coverage and ledger-vs-bills tie-out.
- **The Stack**: TypeScript / Next.js, Postgres, Supabase, SQL, and what would change at scale.

Open `index.html` in a browser. It is a single self-contained file.

All interface examples use invented demo data. No tenant, guest or staff information is included.
